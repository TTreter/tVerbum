Como usar o tVerbum e importar o Editor no seu Sistema Web

Opção 1: Apenas solicitar o JSON (Headless Facilitador) e usar no seu sistema

const res = await fetch('http://localhost:8000/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    video_url: 'https://www.youtube.com/watch?v=...',
    session_number: '21/2026',
    preset_id: 'camara_exemplo'
  })
});
const ata = await res.json();
// ata.body           -> Texto formal da ata pronto para exibir e revisar
// ata.extracted_data -> { session_date_iso, start_time, end_time, present_members, voted_matters }
// ata.review_warnings-> Termos sugeridos para conferência rápida

Opção 2: Importar o componente <tverbum-editor> pronto no seu sistema

<script src="http://localhost:8000/tverbum-editor.js"></script>
<tverbum-editor id="meu-editor" api-base="http://localhost:8000" show-save-button></tverbum-editor>

<script>
  const editor = document.getElementById('meu-editor');
  editor.setMinute(ata); // Carrega o JSON gerado pelo tVerbum

  // Escuta quando você clica em "Salvar Ata" para gravar no seu banco de dados:
  editor.addEventListener('tverbum-save', (e) => {
    const ataRevisada = e.detail; // contém ataRevisada.body com as suas edições!
    salvarNoMeuBancoDeDados(ataRevisada);
  });
</script>
